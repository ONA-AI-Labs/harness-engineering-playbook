# Installing the skill

Claude Code: copy this folder to `.claude/skills/harness-playbook/` in the repository (or `~/.claude/skills/` for every repository), then invoke it with `/harness-playbook`.

Codex: copy it to `.codex/skills/harness-playbook/` or `~/.codex/skills/`.

Set `HARNESS_PLAYBOOK_DIR` to a local checkout of the playbook so the skill reads templates from disk instead of cloning.
